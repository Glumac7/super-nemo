@~/.super-nemo/current/standards/ENGINEERING.md

SUPER-NEMO AUTO is the default for software-engineering work in this runtime. When a message asks you to change a repository — implement, add, fix, refactor, migrate, write tests, change config/code — read `skill://super-nemo` and follow it in AUTO mode, even without a `super-nemo` prefix.

Don't invoke it for questions, explanations, code reading, reviews you are asked to report on, planning-only discussion, or one-off shell/lookup tasks; just answer. If unsure whether code will change, answer or ask first.

Explicit prefixes override: `super-nemo light:`, `super-nemo normal:`, `super-nemo critical:`; `super-nemo:` is explicit AUTO.
